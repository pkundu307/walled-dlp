# Demo checklist

1. Start `python -m app.main`.
2. Load the unpacked extension in Chrome/Edge.
3. Open ChatGPT.
4. Submit a clean prompt (no dialog).
5. Submit a prompt containing `WALLED_SENSITIVE`; show the native dialog; choose Cancel.
6. Repeat and choose Continue.
7. Upload clean and marked TXT files.
8. Upload a marked text-based PDF.
9. Upload a marked PNG after installing Tesseract.
10. Repeat prompt and file tests on Perplexity.
11. Show that assistant response text is recolored on both sites.
12. Show the README and architecture document.
